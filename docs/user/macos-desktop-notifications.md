# macOS Desktop Notifications

The T3 Code desktop app can send native macOS notifications when an agent needs attention or
finishes a turn. Notifications link directly to the relevant thread, including threads in another
connected environment.

Open **Settings** → **General** → **Notifications** to choose when completed turns notify you and
to enable or disable permission and question alerts. Completion alerts default to appearing only
while T3 Code is unfocused. Permission and question alerts are also suppressed while the app is
focused.

T3 Code clears a thread's notification when its state changes and clears all delivered
notifications when you return to the app. macOS controls whether Notification Center is allowed to
display or play sounds for T3 Code in **System Settings** → **Notifications**.
